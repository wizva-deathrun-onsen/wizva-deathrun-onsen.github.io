# WizVD 送死流對話選項紀錄 / WizVD Death-Run Onsen Dialogue Guide

《辟邪除妖 Variants Daphne》（ウィザードリィ ヴァリアンツ ダフネ）送死流泡泉水的固定對話正確選項，以及遣散有緣人後的緣份整理。

網站：https://wizva-deathrun-onsen.github.io/

## 什麼是送死流

隊伍在冒險中有成員陣亡後去泡泉水，會觸發該角色特殊且固定的對話（與一般泉水的隨機對話不同）。選對選項會增加好感度，且同性格的隊員會一起增加；好感度滿即可結緣，遣散有緣人後獲得對應的能力加成（力／智／敏／信／命／靈）。

## 功能

- 依性格、屬性、緣份多選篩選，名稱／選項內容關鍵字搜尋，多種排序
- 角色名稱同時列出中文與日文
- 篩選條件會保留在網址上，複製網址就能分享目前的篩選結果
- 手機版自動改為卡片排版；支援深色模式
- 每一列都有「回報」連結，透過 GitHub Issue Form 回報資料

## 回報資料

點網站上的「回報新角色／修正資料」，或直接開 [Issue 範本](https://github.com/wizva-deathrun-onsen/wizva-deathrun-onsen.github.io/issues/new?template=dialogue-report.yml)。
審核後會更新到網站，並在頁尾列出補充者。
